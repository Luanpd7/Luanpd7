

# 👋 Olá, eu sou Luan Pereira

### Desenvolvedor de Software Júnior

## 👨‍💻 Sobre mim

Sou formado em Análise e Desenvolvimento de Sistemas e iniciei minha
trajetória na área de tecnologia em agosto de 2024.

Durante minha experiência profissional, trabalhei principalmente com
Flutter, atuando no desenvolvimento de dois projetos. O primeiro foi um
sistema de vendas voltado para representantes comerciais, no qual fui
responsável pelo desenvolvimento do front-end para dispositivos mobile
e desktop.

No segundo projeto, tive a oportunidade de aprender e trabalhar com
Go (Golang), desenvolvendo uma aplicação web voltada para gestores,
utilizada para administrar e acompanhar o sistema de vendas desenvolvido
anteriormente. Nesse projeto, atuei como desenvolvedor Full Stack,
trabalhando com Go no back-end e Flutter no front-end.

Tenho interesse em aprender novas tecnologias e continuar evoluindo
profissionalmente na área de desenvolvimento de software.

Além da área de tecnologia, também tenho grande interesse pelo mercado
financeiro, especialmente em entender o funcionamento dos bancos,
sistemas financeiros, investimentos e aspectos relacionados à tributação.

Atualmente, estou estudando conceitos de AWS e buscando aplicar esses
conhecimentos em meus projetos, com o objetivo de ampliar minha
experiência com computação em nuvem.
